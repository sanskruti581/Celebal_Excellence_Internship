# Delta Lake Assignment using Azure Databricks

## Overview
This project demonstrates the implementation of Delta Lake using Azure Databricks.

## Technologies Used
- Python
- Pandas
- NumPy
- Apache Spark
- Delta Lake
- Azure Databricks
- SQL
- Google Colab

## Workflow
1. Create datasets using Google Colab.
2. Clean the datasets using Pandas.
3. Upload the cleaned datasets to Azure Databricks.
4. Create Delta tables.
5. Perform SCD Type 1 MERGE.
6. Create an SCD Type 2 table.
7. Validate the results.
