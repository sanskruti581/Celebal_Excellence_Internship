# Dashboard

Power BI dashboard built directly from the Gold-layer CSV exports (`fact_revenue_bad`, `fact_revenue_good`).

**Files:**
- `Revenue.pbix` — the interactive Power BI report
- `Dashboard_Screenshot.png` — static preview

**What's inside:**
- KPI cards: Revenue & Payments (Bad vs Good pipeline), Orders Missing Payment, Total Cleaned Orders
- Monthly revenue trend (Bad vs Good)
- Order status breakdown (Cancelled vs Completed)
- Payment method distribution
- Revenue by channel

See the [root README](../README.md) for KPI definitions and the story behind the numbers.
