# SQL Advanced Analytics – Superstore Dataset

## 📌 Overview

This project demonstrates the use of **Advanced SQL** concepts to analyze the Superstore dataset. It includes data preparation, customer sales analysis, and business insights using **Subqueries, CTEs, JOINs, and Window Functions**.

## 🎯 Objective

- Import the Superstore dataset into MySQL.
- Create `customers`, `orders`, and `products` tables.
- Analyze sales using advanced SQL queries.
- Generate customer rankings and business insights.

## 📈 Analysis Performed

- Orders above average sales
- Highest sales order per customer
- Total sales per customer
- Above-average customers
- Customer rankings
- Top & Bottom 5 customers
- Customers with a single order
- Highest order value per customer
